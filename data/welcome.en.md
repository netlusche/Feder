# Welcome to Feder

Feder is a calm place to write. You write **Markdown**, and on the right you instantly see how it looks. Export finished texts as *HTML*, *Word*, *LibreOffice* or *PDF*.

## Two modes for focused writing

> **Focus mode** (Ctrl + D): Only the sentence you are writing stays bright. The line stays centered, like on a typewriter.

> **Hemingway mode** (Ctrl + Shift + H): Deleting is disabled. Write first, edit later.

## Handy shortcuts

| Action | Keys |
|---|---|
| Bold, italic | Ctrl + B, Ctrl + I |
| Insert link | Ctrl + K |
| Heading 1 to 3 | Ctrl + 1, 2, 3 |
| Search | Ctrl + F |
| Export | Ctrl + E |
| Full screen | F11 |

All important formatting is also available as **buttons at the bottom left**: text, structure (headings, lists, quote) and insert (link, image, table, code). Each button shows its shortcut in a tooltip.

Lists continue automatically when you press Enter:

- Second thought

Enjoy writing!
